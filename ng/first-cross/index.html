1 · The target genotypes

Path A, label in GAL4. Both ppk arms are possible. The target is PPN1 only.

w ; ppk23-GAL4 / GMR56C09-lexA(attP40) ; UAS-brp-D3-Cherry / LexAop2-myr4xSNAPf(VK00005)

Path B, label in LexA. One arm only. Any GAL4 or split-GAL4 target.

w/Y ; ppk23-LexA / + ; target-GAL4 / UAS-myr::GFP     plus LexAop2-Brp-mCherry
PathArms possibleTargets possibleUse it for

No ppk25-LexA line exists. This is why path B has one arm. PPN1 receives almost equal input from the two groups, thus path A does not test the receptor assignment.

9 · Order of work

  • Set up the two clean-up crosses and the target side of path B. All these stocks are in the laboratory.
  • Both synapse labels come from the Cambridge Genetics stockist. LMB-494 is the label of path A. GJ948 is the label of path B. The laboratory vials of GJ948, GJ1008 and GJ1000 are dead.
  • Set up Parent 1 when LMB-494 arrives. Set up the sensory side of path B when GJ948 arrives.
  • Order Acryloyl-X, sodium acrylate and the benzylguanine dye in the same week.
  • Practise the gel on a ventral nerve cord. These sensory neurons have no presynapse in the brain.
  • Measure the expansion factor of each gel with a landmark of a known size.
