Receptor types of contact chemosensory neurons

Reference points for the ppk23 against ppk25 input split at second order target neurons. Male CNS connectome, male-cns:v1.0.

Working page · Florian Kämpf · 12 August 2026 · Related pages: AN05B102, AN05B023b/c, AN09B017.

Jump to the sensitivity table, the method, what to do next or the Ir52 arm.

1 · The question

A collaborator gave a receptor type to each sensory neuron type. He used the downstream partners of these neurons to do this. But the paper makes a claim about the same downstream partners. This is a loop.

You cannot use the downstream partners two times. You cannot use them first to find the receptor type, and then again to show what the receptor type does. More connectome analysis does not break this loop. Only a measurement outside the connectome breaks it.

This project does not assign receptor types. It establishes empirical reference points. For a set of ascending neurons and other second order targets, it measures what split of ppk23 against ppk25 input each one receives. The receptor assignment stays an assumption on this page. The page shows how much each predicted number depends on that assumption.

The wing types are the historical entry point of the typing argument. Earlier versions of this analysis optimised for the wing types, because WG3 and WG4 came first and the leg assignments were propagated from them. That order is correct as history and wrong as a deliverable. The paper is about contact chemosensation, and the male fly taps the female with the front leg. Thus the leg assignment is the part that must be correct.

2 · What the connectome says

The connectome gives a predicted number for each target neuron. That number is R, the share of the contact chemosensory input that comes from ppk25 positive cells. This section reads the equation in the forward direction only.

What the equation says

R[j] = Σᵢ xᵢ · C[i,j] ⁄ Σᵢ C[i,j]

TermMeaningKnown?Example
jOne target neuron. You pick it.You choose it PPN1
iOne sensory neuron type. There are eight in the ppk family. Fixed listWG3, WG4, LgLG1a, LgLG1b, LgLG5, LgLG6, LgLG7, LgLG8
C[i,j]How many synapses type i makes onto target j.Known, from the connectome WG3 makes 5701 synapses onto PPN1
x[i]Is type i ppk25 positive? Write 1 for yes and 0 for no.Unknown. This is the receptor assignment, and it is the assumption under test. The paper says WG3 is 1 and WG4 is 0
Σ[i]Add up over all eight types. n/an/a
R[j]The share of the input to target j that comes from ppk25 positive cells. Predicted here. A measurement gives the reference point.0.41 for PPN1

In words: the top line adds up the synapses that come from ppk25 positive types only. The bottom line adds up the synapses from all eight types. Divide one by the other and you get a share.

The multiplication by x[i] is a switch. When x[i] is 1, that type counts in the top line. When it is 0, that type gives zero and drops out. So the top line keeps only the ppk25 positive types.

Read the next warning before you treat PPN1 as the experiment.

PPN1 is circular as a test of the assignment. The functional connection from ppk23+ and ppk25+ cells to PPN1, from Kallman et al. 2015, is constraint C3 in PLAN.md. It is one of the three constraints that produced the receptor call. A measurement at PPN1 therefore tests the method. It does not test the assignment. Section 5 states this again at the top of the experiment.

The two groups mix along the whole dendrite of PPN1. The Kolmogorov-Smirnov D value between the positions of the two groups is 0.02 to 0.06 on the three axes, and 0.08 at most on any principal axis. Thus you cannot separate the groups by position. You must separate them by driver.

One sentence in the paper must change. The paper says that PPN1 gives evidence for the receptor type of WG3, and cites the physiology of Kallman et al. 2015. The connectome shows that PPN1 takes almost equal input from the two groups. Thus PPN1 does not select one group, and it is not evidence for a receptor type.

FlyBase gives the name PPN1 to AN05B023 in FBbt:00111517. This is not correct. The connectome gives the name "Kallman 2015: PPN1" to AN05B102a. Also, AN05B102a is cholinergic, but AN05B023a to AN05B023d are GABAergic.

3 · How sensitive the prediction is to the assumption

Every R value on this page is a function of two things. The first is C, the connectome synapse count. The second is x, the receptor assignment. This section measures how much R moves when you change x. It also lists what the calculation treats as exact but is not.

Nobody thinks that all eight receptor types are wrong. The live alternatives are correlated block changes, not single changes. The wing block and the leg block can be right or wrong separately.

The claim that PPN1 has the smallest span is wrong. PPN1 is rank 3 of 57. AN05B102d has a span of 0.490 and IN05B011a has a span of 0.497, against 0.508 for PPN1. The reason to prefer PPN1 still holds in its weaker form. Its 27267 synapses come from many sensory types, so no single type controls it. The targets with a span of 1.000 take almost all of their input from one type, so one flip moves them from one end of the scale to the other. A large number of synapses does not make a target good. The wing targets fail the per body test

Do not use these wing neurons. An independent crosscheck reproduced all 22 R values to inside 0.00045 by two independent methods. It then broke each value down body by body.

INXXX044 has 8 bodies. The per body R values go from 0.071 to 1.000, with an SD of 0.41. One body, 800660, carries 638 of the 863 synapses. If you remove that body, R falls to 0.431, and the prediction inverts.

AN01B004 has 6 bodies in three instance groups. The pair 28192 receives zero ppk input. The pair 57382 gives 170 of the 178 synapses. A type level driver will not reproduce R equal to 0.966.

AN17A003 has an R value of 0.983, and that value is bilaterally consistent: 0.973 on the left, 0.996 on the right, SD 0.015. So its 57 fold separation is real. But only 2 of its 6 bodies receive much ppk input. A type level driver labels all six, so the signal falls by about three times. AN05B096 has the same problem: 4 bodies, 2 with input.

So the targets that look strongest on fold alone are the ones that fail the per body test. The leg targets, which the biology needs, are the robust ones.

What the numbers above treat as exact, but is not

  • The type boundaries come from a clustering whose stability nobody has tested. If the clustering moves, the columns of C move, and not only x. Task 1.4 in PLAN.md describes the test.
  • The entry nerve is unresolved for most sensory bodies. Thus any figure that uses T1 only is a lower bound, and the wing against leg split of C is a lower bound too.
  • R is a share only if every ppk25 cell is also a ppk23 cell. Nobody has checked this. The two drivers are different constructs: ppk23-GAL4 uses a 2.695 kb fragment, and ppk25-GAL4 uses a genomic fusion. If the ppk25 set is not inside the ppk23 set, the share is not a share.
  • The equation assumes that the two drivers show exactly the eight sensory types. But 417 sensory neurons in five types have no receptor type at all. And four of the eight types have no molecular evidence.
  • Hopkins, Barmina and Kopp 2023 report four gustatory classes in one tarsal segment at the pupal stage. A claim that only two of those four classes are ppk23 positive is used in discussion here. That claim is not in the abstract, and nobody on this project has checked it. Read the paper.

Hopkins, Barmina & Kopp 2023, PLoS Biol 21:e3002148. 10.1371/journal.pbio.3002148

What one measurement at PPN1 can and cannot tell you. PPN1 is the best conditioned target: many synapses, a clean pair of bodies, a middle value, and the only driver. But its R value is almost exactly the sum of WG3 and LgLG1b. It cannot see the other four sensory types at all. Measured to plus or minus 0.20, it rules out 112 of the 256 possible receptor assignments. That is under one bit.

The third option is the best measurement. The first option is the only one you can start now. Those are two different decisions, and the sections below keep them apart.

Nothing cancels for a single reference point

An unknown factor k changes the puncta count. The factor k is different for each driver. The factor k also changes with the target neuron, the neuropil and the dendrite. Thus you cannot compare two different target neurons directly, and no measured R is directly comparable to a connectome R.

This fact survives the retirement of the two target design. The old design compared two targets and took a ratio of ratios, so k cancelled. A reference point is one number for one target, so nothing cancels. Targets differ in R because they take input from different sensory types, and those same types set the detection factor. A spread of two in that factor reorders the list, because most neighbouring pairs in the list differ by less than 1.5 fold.

Option 1: t-GRASP, which you can build now

GRASP puts half a fluorescent protein in each of two neurons. It shows where they touch. The signal is not a synapse. Every problem in this part of the page about the unknown factor, about saturation and about merged puncta comes from that one fact.

Use t-GRASP, and use one orientation

Use t-GRASP. The sensory neurons are presynaptic, and the target neuron is postsynaptic. Both ppk drivers are GAL4. Thus the pre half must sit on the UAS side, and that is BDSC 79040.

The two systems have opposite polarity. Do not mix the halves. t-GRASP puts spGFP11 on the pre half. syb-GRASP and CD4-GRASP put spGFP1-10 on the pre half.

BDSC 79039 is the same pair in the other orientation. It puts the pre half in the target neuron. Keep it for later. It becomes the correct orientation when a ppk-LexA driver exists and the target driver is GAL4.

The full t-GRASP set is BDSC 79037 to 79042, and all six sit on chromosome 3.

t-GRASP puts the pre half at the active zone. It puts the post half on mouse ICAM-5. ICAM-5 is a dendritic adhesion molecule, and it fills the full dendrite. Thus t-GRASP compares an active zone with a full dendrite. It does not compare an active zone with one postsynaptic site.

t-GRASP gives false signals. In the control of Shearin et al. 2018 the false signal fell to the limit of detection. It did not fall to zero. The same paper gives two false positives. The authors write that t-GRASP is not infallible, and that a positive result needs a second method. Plan a second method from the start.

GRASP adds up over time. The bond between the halves is not covalent, but it comes apart very slowly, and the colour forms once and stays. Thus a signal tells you that the two neurites touched at some time while the drivers were on. It does not tell you that they touch now.

Shearin, Quinn, Mackin, Macdonald & Stowers 2018, J Neurosci Methods 306:94. 10.1016/j.jneumeth.2018.05.014

Choose the antibody with care

Most anti-GFP antibodies come from full-length GFP. They bind the first ten strands. Thus they also bind the half that has not joined a partner. If you stain with such an antibody, you image where that half is expressed, and not the contacts.

Other groups solved this by choice of reagent. Macpherson et al. 2015 stain GRASP with mouse anti-GFP, Sigma G6539, at 1:100, and they call it anti-GRASP. The same paper reports that chicken anti-GFP, Abcam ab13970, prefers the free spGFP1-10 half. Thus the second antibody is the counter-stain that shows you the expression pattern.

The paper does not claim that Sigma G6539 sees only the joined complex. The practice is established, but the proof is not published. Test it yourself.

Run this control before anything else. Take a line that carries the spGFP1-10 half and no partner. Stain it and image it in the same way. If it gives a signal, the antibody does not report contacts. Macpherson et al. ran this control and did see extra signal with the CD4 form of the half, and much less with the synaptobrevin form.

Macpherson, Zaharieva, Kearney, Alpert, Lin, Turan, Lee & Gallio 2015, Nat Commun 6:10024. 10.1038/ncomms10024

Why a confocal is probably not enough

A confocal joins puncta that sit close together. On AN05B023c the median distance to the nearest synapse is 0.37 to 0.41 µm. A confocal resolves 0.25 µm across and 0.70 µm along the axis. Thus 35 to 38 percent of the synapses sit closer than the lateral resolution. And 71 to 74 percent sit closer than the axial resolution.

This calculation subsampled the large sets. Therefore it cannot support any claim about a difference between the wing arm and the leg arm. It supports only the general statement that many puncta sit below the confocal resolution. Redo it without subsampling, and then quote one number. This is the only quantitative argument on this page for expansion, so it is worth the hour.

The overlap between LgLG1a and LgLG1b is not the reason to expand. There is one spGFP pair, so the two arms are two different animals. You never separate an LgLG1a punctum from an LgLG1b punctum in one tissue. The reason to expand is the distance between puncta inside one arm.

Expansion microscopy of GRASP is untested

Nobody has imaged GRASP puncta after expansion microscopy. This is true for every organism. A literature search gives zero reports, and a colleague who does expansion microscopy confirms this. Read this as untested. Do not read it as tested and failed.

The two halves hold each other by a non-covalent bond. The spGFP11 strand is RDHMVLHEYVNAAGIT, which is 16 residues, and it is the last of the eleven strands of the barrel. The other half holds the colour. The strand closes the barrel and keeps the solvent out. The covalent chemistry happens inside the other half, not between the halves. Thus the gel can pull the two halves apart.

The strand contains no lysine, and the anchor chemistry holds proteins by their amines. But the strand does not carry the anchor. Its carrier protein carries the anchor, and the force travels along the linker. In t-GRASP the carrier is cacophony on one side and mouse ICAM-5 on the other. Aldehyde fixation also reacts with arginine, histidine and tyrosine, and the strand has all three, so fixation probably ties the strand to its neighbours first.

The risk is not only a loss of light. The other half anchors well. If the barrel opens, the strand has nothing to hold it, and it leaves.

Read the two warnings above before you start the steps below.

  • Stain with the primary antibody first. Then anchor. Then make the gel and expand. This order keeps the gel chemistry away from the split GFP.
  • Always include a line that carries the spGFP1-10 half alone. This line must stay blank.
  • Do not use a denaturing protocol, until somebody tests one on a GRASP positive.
  • Do not use Cy3, Cy5 or Alexa Fluor 647. The gel chemistry destroys these dyes. Use Alexa Fluor 488, CF568 or Atto 647N.
  • Run a pilot on a strong t-GRASP positive first. Image it, expand it, then image it again. Count the puncta before and after.
  • Go if 40 percent or more of the puncta survive and the half-reporter controls stay blank. Stop if less than 20 percent survive.

This 40 percent and 20 percent rule is the only decision rule on this page that is stated in advance. Keep it as long as GRASP is in the plan.

There is also no published expansion microscopy of the adult ventral nerve cord. Thus you would develop two new steps at the same time.

Option 2: count real synapses

Lillvis et al. 2022 do not use GRASP. They label real synaptic proteins and read out the geometry. They mark BRP, which is a true presynaptic protein, and they mark the membrane of the partner neuron. Then they ask which BRP sites touch that membrane. Resolution does the work.

How you would run it

  • ppk23-GAL4 tags BRP in the ppk23 cells. Use the STaR method.
  • R56C09-lexA marks the membrane of PPN1.
  • Count the tagged BRP sites that touch that membrane.
  • Repeat with ppk25-GAL4.

This needs two binary systems, and you hold both. The connectome numbers for PPN1 are 27267 and 11075. Read the next warning before you treat those as the expected counts.

What you gain. The result is a synapse count, which is the same quantity as the connectome number. Thus you compare counts, not ratios. There is no split GFP, so the anchoring problem, the antibody problem and the integration over time all go away.

What it costs.

The membrane method undercounts the sites that touch one named partner. For SAG to pC1 they counted 501 against 938 by electron microscopy. A method with a postsynaptic marker reached 729. The undercount should be the same in both arms, so the comparison holds, but the absolute number will sit below the connectome. Do not expect 27267 and 11075.

It is slow. In the 2022 work one sample took about one week to prepare and analyse, and a central brain about five days to image. This sets your sample number.

Option 3: the current dense chemistry

Two names cause confusion. LLSM is a microscope, the lattice light sheet. It is not a method. The method is the gel chemistry, and that is where the two generations differ.

Proteinase K cuts proteins, and it does not keep the ultrastructure. Thus digestion has fallen out of use. Heat denaturation keeps the ultrastructure, and that is why the newer work sees membranes and synapses directly.

Joshua Lillvis no longer uses the 2022 gel chemistry. He now does insect brains with LICONN. This is from a conversation with him in spring 2026, reported by a colleague, and not from a paper. Confirm it with him before you repeat it to anybody.

Why this option measures the right quantity. It counts chemical synapses and it segments the neuron. It does not measure where two membranes touch. Dense contrast also means that you do not depend on a driver line to segment the target neuron. That is the second thing this project lacks, because AN05B023b and AN05B023c have no driver line, and both ppk drivers exist.

This is a meeting abstract, not a paper. The method is not published, and the protocol is not available. Treat the numbers as reported by the authors and not as checked. Ask them directly.

A planning caution about GRASP and this chemistry, drawn on this page. Heat denaturation probably unfolds the barrel and releases the spGFP11 strand. If that is right, the chemistry that keeps the ultrastructure destroys the split GFP, and the chemistry that keeps the split GFP destroys the ultrastructure.

Nobody has published this, and this page has not tested it. The argument also has a hole. It mixes two questions: whether the GRASP fluorescence survives, and whether the GRASP epitope survives. The protocol above stains first and anchors second. Under that order the question is whether an antibody that is bound and anchored before the heat step stays bound, which is a different question from whether the barrel opens.

The choice between the options does not depend on this argument. Choose option 3 because it counts synapses, and not because it destroys GRASP.

5 · What to do next

Read this before the experiment below. PPN1 is constraint C3 in the receptor call, from the physiology of Kallman et al. 2015. So a measurement at PPN1 tests whether the method gives a number that tracks the connectome. It does not test the assignment. Run it to test the method. State that in the pre-registration.

The two crosses that come first

These two crosses need no new transgene. They cost less than any GRASP build, and one of them answers a question that sits under every number on this page.

  • Cross MCFO into ppk23-GAL4 and into ppk25-GAL4. Register the result to a male ventral nerve cord template. Then ask two questions. Is every ppk25 cell also a ppk23 cell? And which sensory types does each driver reach?
  • Cross MCFO into R56C09-lexA and into the four vAB3 lines, so that any number you publish later has a known referent. R56C09 may label AN05B102a only, or also b, c and d. The predicted R differs per cell: 0.41 for a, 0.36 for b, 0.27 for c and 0.78 for d.

Stop rule for the first cross. If the ppk23 driver shows more than 1.3 times or less than 0.7 times the correct number of cells, stop. Do not build the GRASP flies.

Nobody has done these crosses. If several PPN1 cells are labelled and are separable by shape, that gives four calibration points in one animal. If they are not separable, the prediction must be weighted by the cells that the line hits.

The experiment: three groups of animals at PPN1

Use one target, PPN1. Use one reporter. Change only the driver. Each group is a separate set of animals.

Group C is the denominator. It needs no second colour and no second reporter. Divide A or B by C and you get the share of all input. Group C also makes the number comparable between targets, because each target gets its own total, in the same assay, on the same day.

The counts behind the predictions, from male-cns:v1.0. PPN1 receives 33476 input synapses. 27267 of them come from the ppk family, which is 81 percent. 11075 come from the ppk25+ group, which is 33 percent of the total. The ratio of B to A is 0.41, which is R.

This design has had no adversarial review. The two target design that it replaced had eleven reviews. This one has none. Four items are open.

1. The 0.81 in group A assumes that ppk23-GAL4 labels every cell of the ppk family. That is the thing the first cross above measures. Until then, 0.81 is not a prediction, it is the assumption written as a number.

2. The elav-GAL4 line is not located. The table below says to check the line you hold. The denominator of the design is an unlocated reagent.

3. Group C will saturate. elav labels every neuron, so PPN1 receives 33476 synapses of signal on one arbour. That is a solid block, and you cannot count puncta in it. Thus group C works as an intensity, not as a count. Then groups A and B must also be read as intensity, or the three do not compare. An intensity is not a share of input.

4. elav also labels the target. PPN1 is a neuron. Thus elav puts the pre half inside PPN1, and PPN1 already carries the post half from the LexA side. The neuron can then make a signal with itself. Test this before you run the group. A driver that misses the target avoids it.

Note also that dividing B by A brings back the subset question: B over A is a share only if every ppk25 cell is also a ppk23 cell.

Only one target, if you use t-GRASP

Both ppk drivers are GAL4. Thus the target driver must be LexA. The laboratory holds one target LexA: R56C09-lexA for PPN1.

SS103018 for AN13B002 does not help under this route. It is a split-GAL4, so it uses the same binary system as the ppk drivers. It gives a target with no sensory driver left to pair with it. The same is true of the four vAB3 lines, SS103089, SS104905, SS104909 and SS105464.

Thus the panel has one point. This follows from the reagents, and not from the choice of targets. A second point needs ppk25 in a second binary system, and ppk25-LexA does not exist anywhere.

This constraint is conditional on t-GRASP. It also holds for the BRP and membrane route, which needs the same two binary systems. It does not hold for the dense route in section 4, which segments the target neuron without a driver. Under that route AN13B002, AN05B023b and AN05B023c come back.

Find the driver lines

The critical path is not the genetics. It is the driver lines for the targets.

  • Use the hemilineage 23B. It has neurons on the two sides of the LgLG1a and LgLG1b pair, which are IN23B025 and IN23B011. One hemilineage makes the search for driver lines more easy.
  • Look at DNpe029 early. It is a descending neuron, and the Namiki and Card split-GAL4 collection has many descending neurons. Thus you can possibly find this driver line more quickly.
  • Make the MCFO imagery of the four vAB3 lines before you use them. The AN09B017 neurons have R values from 0.090 to 0.896. A line that shows more than one of them gives an R value near 0.35. That result looks like a true negative. Thus a line that you do not characterise is worse than no line.
